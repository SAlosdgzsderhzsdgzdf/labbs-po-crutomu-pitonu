Как запускать
1. Установить библиотеки:
pip install numpy scipy cython


2. Запустить файлы по порядку.
3. Для задания 3 сначала запустить 3_Создание.py, затем 3_Работа.py.
4. Для задания 5 положить 5_Cython.py и helpme.pyx в одну папку и запустить 5_Cython.py.
Для автоматической компиляции Cython на Windows потребуется установленный C/C++ компилятор.
